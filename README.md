# Cổng Thông Tin Điện Tử - MTTQ Ấp Tân An

Website chính thức của **Ban Công Tác Mặt Trận Ấp Tân An**, xã Tân Thành Bình, tỉnh Vĩnh Long. Dự án được thiết kế với giao diện hiện đại (Phiên bản 5.0), tối ưu hóa trải nghiệm trên thiết bị di động, tích hợp tính năng đăng bài viết trực tiếp trên trình duyệt sử dụng `LocalStorage`.

## 🌟 Tính Năng Nổi Bật

* **Giao Diện Hiện Đại (v5.0):** Xây dựng trên nền tảng Tailwind CSS, tương thích hoàn hảo với điện thoại và máy tính.
* **Quản Lý Bài Viết Động:** Cho phép người dùng tạo và đăng bài viết trực tiếp qua giao diện web.
* **Bảo Mật Bằng Khóa (Key):** Tính năng đăng bài được bảo vệ bằng mã khóa bảo mật `KhangPanh68`.
* **Lưu Trữ Cục Bộ (LocalStorage):** Toàn bộ bài viết mới được lưu tự động trên trình duyệt, không cần cơ sở dữ liệu phức tạp.

## 🛠️ Công Nghệ Sử Dụng

* **HTML5 / CSS3**
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** (ES6+)
* **HTML5 LocalStorage API**

## 📱 Hướng Dẫn Sử Dụng Trên Acode / TrebEdit (Android)

1. Tải hoặc sao chép mã nguồn vào file `index.html`.
2. Mở file bằng ứng dụng **Acode** hoặc **TrebEdit**.
3. Chạy xem trước trực tiếp (Preview) trên thiết bị di động.

## 🚀 Hướng Dẫn Đưa Lên GitHub Pages

1. Tạo một Repository mới trên GitHub (ví dụ: `mttq-tan-an`).
2. Tải file `index.html` lên repository ở nhánh chính (`main` hoặc `master`).
3. Vào phần **Settings** của repository -> Chọn **Pages** -> Tại mục *Build and deployment*, chọn nhánh `main` và thư mục `/ (root)` rồi bấm **Save**.
4. Truy cập đường dẫn công khai do GitHub cung cấp sau 1-2 phút.
